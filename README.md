# floorplan-to-3d

把场地平面图变成可布置的 3D 空间时用的 **Agent Skill**（公开示意）。

**一句话：**先认墙门柱，再让人确认比例，最后挤出壳体——确认前不报米数。

## 六步（示意页）

1. 上传 PNG / JPG  
2. 识别：只报结构  
3. 比例：最长外墙真实长度 + 第二条尺寸复核  
4. 清单：漏墙 / 误认家具 / 门洞  
5. 挤出：层高默认 4 m  
6. 兜底：底图 + 手填长宽（顶栏常驻提示）

打开 [`demos/index.html`](demos/index.html) 可点通全流程。代理指令见 [`SKILL.md`](SKILL.md)。
